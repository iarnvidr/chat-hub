# Native updater smoke

On hosted Apple Silicon macOS, this harness compiles independent, disposable 0.1.0 and 0.1.1 source fixtures and exercises the real signed updater. The compile-time Cargo package version is the version returned by the actual `update_status` IPC command (`env!("CARGO_PKG_VERSION")`); it is not supplied by the bundle plist. The fixture preparation rewrites the package manifests, Tauri config and package metadata before compiling, then the runner verifies the compiled executable hashes differ and that both initial bundles contain the old executable. The behavioral driver asserts old `update_status` before offering/installing 0.1.1, then checks fresh-process executable identity and 0.1.1 status after install. Tampered payload must be rejected while the old version remains running: the driver re-queries actual `service_info` and requires its compile-time version to remain 0.1.0, PID to remain the original child PID, and executable path to remain the original bundle binary. It separately verifies the installed bundle plist remains at 0.1.0; this disk-only check is not treated as proof of the live process identity.

Provider proxy interception/capture and the full provider/UI smoke remain advisory and UNVERIFIED on macOS. Release-blocking requirements remain the production packaged-app launch and health checks, startup poke and survival gate, Apple-event checks, DMG build/mount verification, signed updater archive and independent pinned-key verification, and generated `latest.json` validation. The basic native launch/bridge gate is required and fails closed; advisory provider/UI failures cannot weaken these requirements. No published release or feature parity is implied.
